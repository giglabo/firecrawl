## Концепция

### Что такое MCP — и почему это меняет всё

**Model Context Protocol — «USB-порт для AI»**

MCP — открытый стандарт, который позволяет AI-моделям нативно подключаться к твоим сервисам. Не через костыли и промпты, а через протокол. Claude видит твои инструменты так же, как свои встроенные.

Кастомный MCP-сервер — это твоё приложение, которое AI вызывает напрямую. В нашем кейсе Watchword MCP позволяет Claude сохранять и читать данные по ключевым словам без единой строчки дополнительного кода в workflow.

> **Аналогия:** Раньше каждое устройство имело свой разъём. USB объединил всё. MCP делает то же самое для AI — один протокол для любого инструмента.
